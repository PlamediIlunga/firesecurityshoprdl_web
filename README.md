# frontend

# Etape de création du projet : 
```bash
 npm create vite@latest firesecurityrdlshop -- --template react-ts 
 cd firesecurityrdlshop 

```
# Demarrage du projet 

 ```bash
 npm install
 npm run dev pour démarrer

 ```
